# Sales Data Analysis with Python

## Project Overview
This project analyzes sample sales data using Python and Pandas to identify monthly revenue trends and product sales performance.

## Tools Used
- Python
- Pandas
- Matplotlib
- Excel
- Visual Studio Code

## Analysis Performed
- Loaded and explored sales data using Pandas.
- Calculated revenue for each order.
- Analyzed monthly sales revenue.
- Ranked products by quantity sold.
- Created charts for monthly revenue and product quantities.
- Exported the results into a multi-sheet Excel report.

## Project Files
- `sales_analysis.py` — Analysis script
- `sales_data.csv` — Synthetic practice dataset
- `sales_analysis_report.xlsx` — Excel report
- `monthly_sales.png` — Monthly revenue chart
- `top_products.png` — Product quantity chart

## How to Run
1. Install Python.
2. Install dependencies using `python -m pip install pandas matplotlib openpyxl`.
3. Run `python sales_analysis.py`.
4. Review the charts and Excel report generated by the script.

## Dataset Note
This project uses a small fictional dataset for educational and portfolio purposes.

## Skills Demonstrated
Data analysis, revenue calculations, Pandas groupby operations, date handling, data visualization, and Excel reporting.
